# Memoria del proyecto

## Estructura del proyecto
Primero de todo, el jjuego se encuentra estructurado en vistas, de las que partimos de 3 **Esto por ahora** de las que vamos a hablár más en adelante:
- Menú principal
- Juego
- "Game Over"

Por otr lado, para todo aquello que vamos a ver, con lo que vamos a interactuar y jugar, se han creado una seríe de clases que son la base del proyecto
- Personajes
- Armas
- Habitaciones

### Menú Principal
Aquí es donde se configurará la dificultad de los enemigos además de los gráficos de los mismo, se guardará una nueva partida con el nombre que será guardada en el ordenador y que servirá para continuar con lo que lo dejaste si has cerrado el juego.
**tengo intención de programar un autoguardado cada x tiempo para que no se pierda nada**

### Juego
Aquí es donde ocurre toda la mágia. dEntro de aquí es donde se encontrarán todos los elementos de nuestro juego, donde se empezará esta aventura
